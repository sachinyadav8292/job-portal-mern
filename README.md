# 🚀 Job Portal - MERN Stack Application

A Full Stack Job Portal web application built using the MERN stack.  
This project includes authentication, role-based access, job posting, job application system, and profile management.

---

## ✨ Features

- 🔐 User Authentication (Login / Signup)
- 👥 Role-Based Access (Student / Recruiter)
- 📝 Job Posting & Management
- 📩 Apply for Jobs
- 🔎 Search & Filter Functionality
- 🖼 Profile Image Upload (Cloudinary)
- 🛡 Protected Routes
- 📱 Responsive UI

---

## 🛠 Tech Stack

**Frontend**
- React.js
- Redux Toolkit
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**Cloud Storage**
- Cloudinary
